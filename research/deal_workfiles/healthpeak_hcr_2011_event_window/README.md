# Healthpeak (HCP) / HCR ManorCare 2011 Event Window

This folder contains a facility-year panel for the HCR ManorCare nursing homes acquired by HCP, Inc. (now Healthpeak) in April 2011.

## Cohort Identification
- **Target:** HCR ManorCare / Heartland facilities.
- **Criteria:** Facilities identified as part of the HCR ManorCare chain in 2011 that were consistently present in LTCFocus from 2009 to 2013.
- **Size:** 244 facilities met the stability criteria for the t+/-2 window.

## Files
- `healthpeak_hcr_2011_panel.csv`: LTCFocus data extract for the cohort (2009-2013).
- `healthpeak_hcr_2011_roster.csv`: List of the 244 unique CCNs, names, and states in the cohort.
- `summary.json`: Metadata and coverage statistics.

## Data Sources
- **LTCFocus:** Primary source for staffing (RN, LPN, CNA HPRD), Medicaid share, and census data for the 2009-2013 period.
- **CMS Archives:** 2013 archive data used for cross-verification.
